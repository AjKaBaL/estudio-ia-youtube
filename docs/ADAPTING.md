# Using this project as a base for your own channel

Estúdio IA YouTube was built for a Portuguese-language channel about technology, AI and innovation, but almost everything that is specific to that channel is configuration or a small, isolated piece of code. This guide shows where to change things.

## 1. Niche: feeds and monitored terms (no code)

In the app, open **Pautas e pesquisas › Fontes e opções**:

- add or remove RSS feeds and pages (paste a site address and click **Identificar** — the app finds the feed);
- edit the **monitored terms** (comma = "or", quotes = exact phrase);
- mark trusted or blocked domains.

The defaults shipped with the app live in [`src/shared/fontesPadrao.ts`](../src/shared/fontesPadrao.ts) — change them there if you want different defaults for a fork.

## 2. Schedule and rhythm (no code)

The **Frequência de publicação** panel on the dashboard (Painel) sets how many long videos and Shorts per week and at what time; **Configurações › Frequência das buscas** sets when research runs. Ready-made rhythms (Leve, Médio, Intenso) are one click each in Primeiros passos.

## 3. Language of scripts and narration

- **Script prompts:** the AI instructions are in Portuguese in [`src/main/roteiros/gerador.ts`](../src/main/roteiros/gerador.ts) (`SISTEMA` and the scene expansion prompt) and in [`src/main/piloto.ts`](../src/main/piloto.ts) (fact dossier). Translate them and ask for your language in the output.
- **Voice:** the neural voice is Piper `pt_BR-faber-medium`, downloaded with a pinned SHA-256 in [`src/main/midia/voz.ts`](../src/main/midia/voz.ts). Pick another voice from the [Piper voice list](https://huggingface.co/rhasspy/piper-voices), update the URLs **and** the SHA-256 hashes. The Windows built-in voice is the fallback.
- **Interface:** the UI is in Portuguese (`src/renderer`). It works as is for any language of content; translating the UI is a larger, optional job.

## 4. Presenter character

The animated presenter is an original drawing generated by [`scripts/apresentador.py`](../scripts/apresentador.py) (Python + Pillow). Change colors, the chest label or the poses, then run:

```
python scripts/apresentador.py
python scripts/icone.py
```

The first command regenerates the PNGs in `recursos/apresentador/` and the embedded art in `src/main/midia/apresentadorArte.ts`; the second regenerates the app icon. The presenter can be turned off in **Acabamento do vídeo**.

## 5. AI providers

The app routes each task to the providers you configure in **Configurações › Serviços de IA**: a local model through [Ollama](https://ollama.com/) (installed with one click) and optional free-tier cloud APIs with your own keys. Keys are stored encrypted on your computer and never in the database or the repository.

## 6. YouTube account

Publishing uses the official YouTube Data API with **your own** Google Cloud project (OAuth "Desktop app" credential). Step-by-step rules and limits are in [`packages/youtube/REGRAS.md`](../packages/youtube/REGRAS.md). The YouTube code is isolated in that package, so API changes only touch it.

## 7. Editorial and safety rules

The fact-checking rules (two independent sources or one primary source per claim, exact excerpts, no invented numbers or quotes) and the quality gates that block publishing are deliberate. You can tune thresholds — for example `MIN_AFIRMACOES` in `src/main/piloto.ts` — but please keep the spirit: the project exists to make original, well-sourced videos, not mass-produced content.

## 8. Check your changes

```
npm run verificar
```

runs type checks, lint and the test suite. Tests never install anything or touch the internet; optional real-FFmpeg tests run only with `FFMPEG_REAL=1`.

## 9. Ground rules worth keeping

- Never commit secrets or personal data: API keys, OAuth tokens, `client_secret*.json`, the database (`*.sqlite`) and user media stay out of the repository (already in `.gitignore`).
- Spawn commands with argument arrays; never build shell commands by concatenating text.
- Tests must not install software, download files or change anything on the computer running them.
- Keep YouTube API code inside `packages/youtube`.
- Keep the editorial safeguards: no invented sources, quotes or numbers; provenance and license for every asset; no publishing with critical fact-checking or quality issues.
